# gqlify_runtime

Lightweight pure-Dart runtime for code generated by
[gqlify](../gqlify):

- `GqlifyClientBase`: base class of generated clients
- `GqlifyTransport`: injectable transport interface, with `HttpTransport` on
  top of `package:http` (Dart VM, Flutter, web)
- typed `GqlifyResponse`, `GraphQLError`, and the sealed `GqlifyException`
  hierarchy
- `MockTransport` in `package:gqlify_runtime/testing.dart`, for tests without
  a network

No Flutter dependency and no global mutable state.
