# gqlify

Build-time GraphQL code generator for Dart and Flutter: typed operations and
concise client methods from a schema and `.graphql` documents.

Add it as a dev dependency together with
[`gqlify_runtime`](../gqlify_runtime), create `gqlify.yaml`, and run
`dart run gqlify generate`. See the [repository README](../../README.md) for
usage and [ARCHITECTURE.md](../../ARCHITECTURE.md) for the design.
